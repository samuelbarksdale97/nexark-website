## Structured data suggestions

- Use `Article` for canonical papers and Federalist essays.
- Use `TechArticle` only for the Method Specification and highly technical implementation pages where appropriate.
- Use `FAQPage` for the FAQ, provided rendered questions and answers match the structured data exactly.
- Use `CollectionPage` for the canon, Federalist index, Evidence Center, and Casebook.
- Use `Person` for Sam Barksdale and `Organization` for Nexark.
- Do not use academic credentials, review ratings, or institutional affiliations that have not been established.
